# Folder: /src/bento/widgets

1. **Status**: 当前卡片类型、渲染器与链接平台识别。
2. **Logic**: `types.ts` 定义 `WidgetConfig`（link、image、text、map、section）；其中 image 卡片可承载静态图片、Live Photo 和视频组成的混合媒体图集；`index.tsx` 渲染；各类型组件处理自己的显示与编辑交互；`registry.ts` 识别链接平台。
3. **Constraints**: 新卡片需与 `WidgetConfig`、渲染器、编辑器和 SQLite 快照兼容；内联编辑不得误触画布选择/拖放。

现有类型目录：`link/`、`image/`、`text/`、`map/`、`section/`。旧独立 GitHub、Spotify 卡片文件已移除；这些平台目前按链接卡片处理。

Link 卡片可按账号分别创建；`link/importLinks.ts` 解析 CSV 或 JSON 批量导入，每张卡片使用独立 UUID。背景图由 `backgroundImage` 保存，可在创建时填 URL 或在编辑面板上传。
Link 卡片的 `collection`、`tags`、`onCanvas` 和 `linkHealth` 随原 Space 快照保存；未放在画布上的链接仍保留在收藏夹。
