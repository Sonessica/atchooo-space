# Folder: /src/bento/editor

1. **Status**: 当前单页 Bento 编辑器的画布、交互与持久化桥接。
2. **Logic**: `InfiniteCanvas.tsx` 负责视口、平移与拖放交互，`canvasPlacement.ts` 对完整占格、修复、交换与多卡推挤做纯计算；`EditorContext.tsx` 管理卡片/资料；`PersistentEditorProvider.tsx` 读取快照并自动保存。
3. **Constraints**: 当前共享快照使用一组 `widgets`；任意落点必须通过完整占格检查，不能回退到未经验证的坐标；改保存时保留 revision 冲突处理。

`sectionGroups.ts` 管理显式分区归属、删除解组、范围预选；Title 的内容/样式/成员管理在 `WidgetEditorPanel.tsx`，画布提供多选建组、框选确认、折叠卸载和整组拖动。`canvasPlacement.ts` 按实际成员占格进行原子整组移动，并保留外部分区及自动布局中的相对坐标。折叠不释放占格；访客折叠不写共享快照。

其他入口：`EditorToolbar.tsx` 添加卡片并上传图片、Live Photo 或视频，`ImageEditorModal.tsx` 管理混合媒体图集，`WidgetEditorPanel.tsx`/`WidgetEditOverlay.tsx` 编辑内容，`SettingsModal.tsx` 管理个人资料，`LocationSearch.tsx` 调用 Nominatim。`EditorLayout.tsx`、设备检测等仍供旧版布局使用。

`LinkImportModal.tsx` 在当前 Space 批量导入 CSV/JSON 链接，可预览数量后确认。
`LinkLibraryPanel.tsx` 汇总四个 Space 的链接，管理标签、收藏夹、画布显隐和手动失效检查。画布布局只处理 `onCanvas !== false` 的链接。
